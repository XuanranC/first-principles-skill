# First Principles（第一性原理）Skill

一个装在 AI 里的「第一性原理」实战思考技能包（支持 Claude Code、Codex、Claudian、OpenClaw、Antigravity 等工具）。

现实中绝大多数看似棘手甚至无解的困扰——无论是**商业判断、工作卡点、项目方案、个人重大取舍，还是复杂的技术故障**——之所以让人焦头烂额，往往是因为我们在表象上兜圈子。只要退回到事物的**第一性原理**把底层逻辑看清，很多复杂问题其实迎刃而解。

这个 Skill 只做两件事：**第一，用第一性原理帮你把眼前的真问题彻底拆穿、解决掉；第二，在陪你解决一个个真实难题的过程中，让你自己也长出用第一性原理思考问题的能力。**

---

## 一、这个 Skill 是干什么的？

用一句大白话讲清什么是**「第一性原理」**：
遇到任何事，不盯着表面症状打补丁，也不盲目照搬“别人通常怎么做”，而是把所有猜测、情绪和包装全剥掉，一直往下追问，退回到这件事**最底层、谁都无法推翻的客观事实和运转规律**上，再顺着它往上找答案。

装上这个 Skill 后，你不需要懂任何哲学理论或提示词技巧，平时遇到任何拿不准或搞不定的事，直接像日常说话一样丢给它就行：

1. **遇到棘手难题、试了各种办法都没用时**（业务停滞、流程卡壳、工具异常等）：它不甩试错偏方，而是帮你还原底层运转机制，直接锁死唯一出问题的一环。
2. **写方案、定计划、准备投入成本干一件事时**：它帮你揪出“只是看同行有、所以我也想搞”的模仿动作，砍掉 80% 冗余，只留直达目标的最短路径。
3. **在人生或业务取舍间反复纠结、焦虑内耗时**：它不敷衍地列利弊对比表，而是帮你剥开面子、跟风和模糊的恐惧，先看清你内心真正要解决的问题是什么。
4. **面对热门风口、复杂现象或别人的建议，拿不准真假时**：丢给它“脱水”，抽干黑话与包装，直接算清底层的因果链和成本价值硬账。

## 二、为什么必须装这个 Skill？（警惕人与 AI 的「表象共振」）

很多人会问：我现在已经有大模型了，遇到问题直接问 AI 不就行了吗？

恰恰相反——如果你留心观察就会发现，很多人在用 AI 时非但没看清本质，反而在错误的方向上越走越远。

> **因为从底层看，大模型的训练机制，决定了它天生就是全人类“流行意见”的最大统计平均机。**

亚里士多德很早就指出，人类思考只有两种起点：一种是**流行意见**（大家都这么说、经验上习惯怎么做），另一种是**第一性原理**（退无可退的底层客观事实）。而在日常用 AI 的过程中，最容易发生一个隐蔽的陷阱——**「表象共振」**：

- **人的省力本能**：遇到困难容易被表面现象蒙蔽，提问时往往带着自己都没察觉的**“默认假前提”**（比如默认“群里热闹就等于能带来复购”、默认“只能在眼前的 A 和 B 里二选一”）。
- **大模型的顺从本能**：大模型按统计概率生成文字，天性就是**讨好顺从你的问题前提，并把全网最常见的平均套话汇总成工整的清单塞给你**。

当“带着假前提的人”遇上“流行意见平均机”，两边就会互相印证、互相放大：
- 墙皮裂了（其实是地基沉了），你问普通 AI：“买什么牌子的腻子补墙最牢？”——它会认真给你测评十款腻子，**绝不会拦住你问一句：“你家地基是不是歪了？”**
- 你问普通 AI：“怎么把这十个繁琐步骤优化得更快？”——它会给你写一套详尽的提速指南，**绝不会先问一句：“这十个步骤本身真的需要存在吗？”**

聊得越热闹，离真相越远。**越是在 AI 随手可用的时代，我们越不能把思考交给“统计平均”，越需要主动回到第一性原理。** 这个 Skill 就是为了切断这种“表象共振”而生——改掉 AI 讨好顺从、堆砌套话的毛病，让它每次开口都带你直奔地基。

## 三、这个 Skill 为什么好？（既帮你解眼前的局，又帮你练自己的功）

市面上有不少“请用第一性原理分析”的简单提示词，用起来往往像在背书或硬套模板。这个 Skill 真正打磨透的地方在于：

### 1. 敢先拆你的「默认假前提」，拒绝帮你在错问题上白费力气
很多事情做不成，是因为问题本身就问偏了。它在给方案前，会先把话里的「客观事实」与「默认前提」拆开审视——一旦发现你在努力优化一个根本不该存在的环节，先直接点破假前提。

### 2. 你描述不清问题也没关系，它会顺藤摸瓜把关键细节挖出来
被表象困住的人，本来就不知道哪些细节重要。当关键事实不全时，本 Skill **严禁 AI 瞎猜或罗列七八条通用建议**——本地能查证的它会亲手去查；需要问你的，每次只用大白话问 1～3 个最核心的具体事实（变化点在哪、当时具体怎么操作的、单独测试正不正常、剥开手段后真正想要什么），一步步帮你把藏在水底下的真问题挖出来。

### 3. 内置三道“到底检验”，严防拿正确的废话冒充深刻
拒绝“商业的本质是提供价值”“一方面要 A，另一方面也要兼顾 B”这类看似正确实则无用的空话。本 Skill 强制模型过三关：**换个表面形式依然行得通就不算到底、同义反复的空话不算到底、推不出排他性取舍不算到底**——逼出真正锋利、算得清硬账的判断。

### 4. 在真事上带练：每解决一个问题，就让你多长一分第一性原理能力
它既不是只吐结论的黑盒拐杖，也不是枯燥讲理论的老师，而是把思考全过程用最朴素的大白话完整摊开给你看（严禁生造故弄玄虚的四字黑话）：
- **追问时**：告诉你遇到乱局第一步为什么要先抓这个事实；
- **推导时**：清晰呈现 `表象与默认前提` → `第一性原理` → `顺着往下推` → `怎么验证与行动`；
- **收尾时**：把刚刚破局的动作，提炼成一句**下次遇到同类事你自己就能直接问出口的底层问题**。

用上几次你就会发现：不仅手头棘手的事一件件解开了，你自己看事情的眼光也变了——哪怕不打开 AI，遇到乱局你也会下意识先问一句：**“先别看表面这么复杂，这件事最底层的第一性原理到底是什么？”**

## 四、安装与使用

### 方式 1：直接让你的 AI 帮你装（最省心）
直接把下面这句话发给你的 Codex、Claude Code 或 OpenClaw：

```text
帮我安装这个 skill：https://github.com/XuanranC/first-principles-skill/tree/main/skills/first-principles
```

### 方式 2：命令行一键安装
```bash
npx skills add XuanranC/first-principles-skill
```

### 方式 3：手动安装
下载或克隆本仓库后，将 [`skills/first-principles`](./skills/first-principles) 文件夹放入你所用工具的 Skills 目录即可（例如 `~/.claude/skills/first-principles`、`~/.codex/skills/first-principles`、`~/.gemini/config/skills/first-principles` 或项目内的 `.agents/skills/first-principles`）。

### 日常怎么用？
- **自动触发**：当你抛出反复试错无果的卡点、纠结的取舍、需要评审的方案或希望看清本质的话题时，AI 会自动启用它；
- **主动调用**：在做任何分析与判断时，直接说一句 *“用第一性原理帮我看看这件事”*（或在支持的环境输入 `$first-principles`）即可。
